# 2. Elección de Vue.js como framework principal

Fecha: 2026-08-31
Estado: Aceptado

## Contexto
El equipo necesita establecer la tecnología base para el desarrollo del frontend. Durante las discusiones iniciales, nos encontramos con un bloqueo debido a preferencias, una parte del equipo prefería no utilizar Angular, mientras que la otra parte rechazaba el uso de React. 

## Decisión
Hemos decidido utilizar Vue.js como nuestro framework de frontend. 
Dado que ningún miembro del equipo tiene experiencia previa trabajando con esta tecnología, Vue actuará como un terreno neutral. 

## Consecuencias
* **Positivas:** 
  * Pone a todo el equipo en igualdad de condiciones, fomentando el aprendizaje conjunto.
  * Vue.js es conocido por tener una curva de aprendizaje progresiva y una excelente documentación, lo que facilitará la adopción por parte del equipo.
* **Negativas:** 
  * Habrá una disminución temporal en la velocidad de desarrollo durante las primeras semanas.
